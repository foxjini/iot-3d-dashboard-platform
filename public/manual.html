1. 플랫폼 및 스마트홈 베이스라인 개요

본 플랫폼은 고등학교 학생들이 팀별 IoT 프로젝트를 수행할 수 있도록 제공되는 완전한 공통 개발용 베이스라인(Starter Platform)입니다. 웹 브라우저의 3D 가상 공간에서부터 Raspberry Pi Pico 2 W 물리 장치 제어까지 100% 정상 작동하는 기본 스마트홈 코드가 탑재되어 있습니다.

환경 센서 (Read)

  • DHT11 (GP15): 실내 온도(℃)와 습도(%)를 측정하여 3D 공간 상단 플로팅 배지와 대시보드에 실시간 표시
  • Cds 조도센서 (GP26 / A0): 주변 밝기를 측정하여 3D 방의 환경광(Ambient Light) 밝기를 동적으로 자동 조절

제어 액추에이터 (Write & Ack)

  • SG90 서보모터 (GP16): 스마트 도어 개폐 각도(0° 닫힘 ~ 90° 열림)를 제어하고 3D 도어 메쉬를 부드럽게 회전
  • RGB LED (GP18, GP19, GP20): 컬러 피커로 색상을 지정하면 3D 방 천장 펜던트 조명이 동일한 색상으로 발광

2. 하드웨어 결선 & CircuitPython 1분 세팅

Pico 2 W는 복잡한 IDE(Thonny 등)가 필요 없습니다. CircuitPython을 사용하면 USB 메모리처럼 code.py 파일만 복사·저장하면 즉시 코드가 실행됩니다!

부품명 Pico 2 W 핀 신호 형태 결선 가이드
DHT11 (온습도) GP15 디지털 VCC(3.3V), GND, DATA(GP15) 연결
Cds (조도센서) GP26 (ADC0) 아날로그 10kΩ 저항과 함께 전압분배 회로 구성 후 GP26에 연결
SG90 (서보모터) GP16 50Hz PWM VCC(5V VBUS), GND, SIGNAL(GP16) 연결
RGB LED GP18, GP19, GP20 PWM 출력 공통 캐소드(GND), Red(GP18), Green(GP19), Blue(GP20)

초간단 3단계 설치법:

  1. Pico 2 W의 BOOTSEL 버튼을 누른 채로 PC USB에 꽂으면 RPI-RP2 드라이브가 뜹니다.
  2. CircuitPython 공식 UF2 파일을 드라이브에 넣으면 CIRCUITPY 드라이브로 재부팅됩니다.
  3. 프로젝트의 firmware/circuitpython/에 있는 code.py와 settings.toml을 CIRCUITPY 드라이브에 복사하세요!

⚡ [핵심] 실물 Pico 보드가 없어도 100% 하드웨어 모드 테스트하기 (Mock 에뮬레이터)

실물 Pico 2 W 장비가 없거나, 학교 실습실 Wi-Fi 보안(AP 격리)으로 Pico와 PC 간 통신이 어려울 때는 프로젝트에 내장된 Node.js 모의 서버(Mock Server)를 실행하여 실제 하드웨어와 100% 동일하게 REST 통신을 테스트할 수 있습니다!

터미널에서 모의 하드웨어 서버 실행:

node firmware/mock_pico_server.js
  • IP 주소 입력: 대시보드 상단 [Pico 2 W 연결 설정] 모달에서 IP 주소로 127.0.0.1:5050을 입력하고 [하드웨어 연동] 모드를 켭니다.
  • 동작 원리: 브라우저 -> Next.js 프록시(/api/pico/[...path]) -> 모의 서버(5050 포트)로 전달되어 CORS 문제 없이 온습도/조도 폴링 및 서보모터/LED 제어 ACK가 실시간 동작합니다.
  • 네트워크 장애 복구(Failover): IP를 잘못 입력하면 화면이 멈추지 않고 빨간색 '오류' 상태로 안전하게 전환되며, 올바른 주소로 수정 시 새로고침 없이 즉시 정상 복구됩니다.

3. 왜 AI가 엉뚱한 코드를 짤까? (Context 엔지니어링의 정석)

🚨 학생들이 가장 많이 겪는 실패 원인:
ChatGPT나 Claude, Gemini 웹사이트에 가서 "우리 프로젝트 스마트팜으로 바꿔줘"라고 한 문장만 말하면, AI는 여러분 컴퓨터에 있는 code.py나 useIoTStore.ts가 어떻게 생겼는지 전혀 볼 수 없습니다!
그 결과, AI는 인터넷에 있는 아무 코드나 상상해서 짜주기 때문에 빨간 줄(에러)이 잔뜩 생기거나 3D 화면이 먹통이 됩니다.
✅ 해결 비결: "마스터 Context 학습 + 구체적 요구사항" 2단계 전략!
  1. 1단계 (뇌 이식): 대화 시작 시 상단의 [플랫폼 전체 마스터 컨텍스트 복사하기]를 눌러 AI에게 우리 프로젝트 전체 구성을 알려줍니다.
  2. 2단계 (요청): 그 다음 아래 5번 섹션의 [프롬프트 1. 스마트팜 변경] 버튼을 눌러 원하는 기능 변경을 요청합니다.
이렇게 하면 AI가 useIoTStore의 액션 이름과 code.py의 REST 엔드포인트를 정확히 알고 완벽한 코드를 만들어냅니다!

4. 팀별 프로젝트 주제 변경 실전 레시피

레시피 1: [스마트팜(Smart Farm)]으로 변경하기

★ 레퍼런스 예시 코드 제공됨

스마트홈의 DHT11(온습도)을 토양 수분 센서(Soil Moisture)로 교체하고, SG90 서보모터를 온실 환기 돔 개폐기로 변경하며, 3D 가상 공간을 온실 돔과 식물 화분으로 바꾸는 절차입니다.

수정해야 할 핵심 4개 파일 체크리스트:

  1. firmware/circuitpython/code.py: GP27(ADC1)에 토양수분센서 객체 생성 및 /api/status JSON에 soil_moisture 추가
  2. src/core/types/iot.ts: soil_moisture 센서 인터페이스 추가
  3. src/core/adapter/MockIoTAdapter.ts: 토양수분(30% ~ 80%) 시뮬레이션 난수 발생기 추가
  4. src/components/3d/SmartHomeRoom.tsx: 온실 유리 돔, 배양토, 식물 메쉬 및 환기 돔 회전 애니메이션 구현
📁 이미 완성된 스마트팜 예시 코드가 프로젝트에 들어있습니다!
프로젝트 내 context/examples/smart_farm/ 폴더를 열어보세요:
- context/examples/smart_farm/code.py (토양수분 펌웨어)
- context/examples/smart_farm/SmartFarmRoom.tsx (3D 온실 컴포넌트)
AI 없이도 이 파일들을 직접 복사해서 쓸 수 있습니다!

레시피 2: [스마트팩토리(Smart Factory)]로 변경하기

1) 하드웨어: Cds 조도 센서 또는 초음파 센서로 물품 통과를 감지하고, 서보모터를 '물품 분류 푸셔(Pusher)' 암으로 제어합니다. RGB LED는 공장 정상(초록)/대기(노랑)/비상정지(빨강) 3단 경고등 역할을 합니다.

2) 3D 씬: 금속 컨베이어 벨트 메쉬를 3D 공간에 배치하고, 물품 상자가 이동할 때 서보모터 푸셔가 밀어내는 애니메이션을 연동합니다.

5-2. 핵심 4대 UI 기능의 구현 원리 및 코드 해설

(1) 우측 3단 멀티탭 시스템 (인스펙터 / 센서 출력 / 제어 로그)

단순한 단일 사이드바가 아니라, 관제 센터에 필수적인 세부 제어(인스펙터), 데이터 계측(센서 출력), 이벤트 추적(제어 로그) 3개 뷰를 조건부 렌더링으로 전환하도록 설계되었습니다: 

// src/app/page.tsx 및 InspectorPanel.tsx
type RightPanelTab = 'inspector' | 'telemetry' | 'logs';

// 탭 전환 버튼 클릭에 따라 동적으로 자식 패널 렌더링
{rightPanelTab === 'inspector' && <InspectorContent />}
{rightPanelTab === 'telemetry' && <SensorOutputPanel />}
{rightPanelTab === 'logs' && <ControlLogPanel />}
  • CSV 데이터 내보내기 구현 (SensorOutputPanel): new Blob([csvContent], { type: 'text/csv;charset=utf-8;' }) 객체를 생성하고 가상 <a download> 링크를 클릭시켜 학생들이 엑셀에서 실험 결과를 바로 열어볼 수 있도록 구현했습니다.

🌟 5-5. 3D 공간 플로팅 UI 및 모달 레이어링 (Z-Index 제어 & Auto-Dismiss)

React Three Fiber (R3F)의 <Html>(Drei) 컴포넌트는 3D 가상 공간 내부에 HTML DOM(말풍선, 센서 배지, 경고 카드)을 띄울 때 매우 유용하지만, 기본 z-index가 약 16,777,271로 극도로 높게 책정되어 있어 일반 CSS 모달 다이얼로그(설정창, 장비관리창 등)를 뚫고 나와 가려버리는 치명적인 UI 결함이 발생합니다.

💡 반드시 준수해야 하는 3대 3D UI 레이어링 공식:

  1. Drei <Html> z-index 범위 제한: 3D 어노테이션 컴포넌트(NeedsYouCallout3D.tsx 등)의 <Html> 태그에 zIndexRange={[10, 0]} 속성을 반드시 지정합니다. 이를 통해 3D 오버레이 DOM의 z-index가 최대 10을 넘지 않도록 안전하게 가둡니다.
  2. 모달 컨테이너 z-index 격상: 화면 전면을 덮는 모든 모달 창(PicoIpModal, DeviceManageModal, ScheduleModal, AddRoomModal, ReviewModal)의 백드롭 컨테이너를 z-[100] 이상으로 지정합니다.
  3. 모달 활성화 시 3D 메시지 자동 숨김(Unmount): 페이지 상위(page.tsx)에서 모달 열림 여부(isModalOpen)를 파악하여 SceneCanvas -> SmartHomeRoom -> NeedsYouCallout3D로 전달하고, 모달이 열려 있을 때는 if (isModalOpen) return null;로 3D 말풍선을 즉시 언마운트합니다.
  4. 일회성 알림 자동 소멸(Auto-Dismiss) & 수동 닫기 버튼: '승인 완료', '동작 확인' 등의 일회성 알림은 화면 중앙에 영구히 남아있지 않도록 setTimeout(..., 4500)을 통해 4.5초 후 자동 소멸시키고, 우측 상단에 ✕ 닫기 버튼을 항상 제공해야 합니다.

7. 트러블슈팅 & FAQ

Q. AI가 만들어준 코드를 넣었는데 화면에 값이 안 뜹니다!

AI가 스토어의 키 이름을 다르게 지었을 가능성이 높습니다. src/core/types/iot.ts의 키 이름과 MockIoTAdapter.ts에서 호출하는 updateSensor('키이름', 값)의 키 이름이 알파벳 대소문자까지 정확히 일치하는지 확인하세요.

Q. Pico 2 W의 IP를 입력해도 '연결 대기' 상태에서 멈춥니다.

1) PC와 Pico 2 W가 동일한 Wi-Fi 공유기에 접속되어 있는지 확인하세요.

2) 학교 와이파이에서 기기 간 통신(AP Isolation)이 막혀있을 경우, 스마트폰 핫스팟에 PC와 Pico를 함께 연결하면 100% 즉시 통신됩니다.

Q. 3D 화면이 검게 나오고 렌더링되지 않습니다.

브라우저 설정에서 [하드웨어 가속 사용]이 켜져 있는지 확인하고 크롬(Chrome) 또는 엣지(Edge) 브라우저를 사용하세요.

Q. 3D 화면 중앙의 '승인 완료' 말풍선이 설정창이나 모달을 가려 클릭이 안 돼요!

Three.js Drei의 <Html> 기본 z-index가 약 1600만으로 매우 높게 잡혀있어서 발생했던 문제였습니다. 최신 플랫폼에서는 zIndexRange={[10, 0]} 적용 및 상위 모달 감지(isModalOpen)를 통해 모달 창이 열리면 3D 말풍선이 즉시 숨겨지도록 완벽히 패치되었습니다. 또한 4.5초 뒤 자동 소멸되며 우측 상단 ✕ 버튼으로 언제든 즉시 닫을 수 있습니다.

Q. Pico 2 W의 IP를 잘못 입력했을 때 화면이 멈추거나 먹통이 되지 않나요?

최신 CircuitPythonAdapter.ts는 요청 실패 시 즉시 안전하게 '오류 (ERR)' 상태로 전이되어 무한 대기(스피너 고착)를 완벽히 방지합니다. 상단 연결 설정 모달에서 올바른 IP 주소로 수정하면 새로고침 없이 즉시 정상 녹색 뱃지로 자동 복구됩니다.

Q. 학교 실습실이나 집에서 실제 Pico 보드가 없을 때 하드웨어 연동을 어떻게 테스트하나요?

프로젝트에 기본 제공되는 node firmware/mock_pico_server.js를 실행하세요! 포트 5050에 모의 CircuitPython REST 서버가 구동되며, 대시보드 IP 입력창에 127.0.0.1:5050을 입력하고 '하드웨어 연동' 모드를 켜면 실물 보드와 100% 동일하게 센서 텔레메트리 수신, SG90 서보모터 회전, RGB LED 제어가 동작합니다.
