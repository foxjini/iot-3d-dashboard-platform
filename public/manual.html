STEP 01 · OVERVIEW & MASTER CONTEXT

1. 스마트홈 3D IoT 플랫폼 개요 & AI 마스터 학습

고등학교 학생 팀 프로젝트를 위해 설계된 3D 가상 공간 ↔ 마이크로컨트롤러(Pico 2 W) 통합 플랫폼입니다.

🚀 [필수 1단계] AI에게 플랫폼 전체 아키텍처 한 번에 학습시키기

ChatGPT, Claude, Gemini, Antigravity 채팅창을 열고 맨 처음에 아래 버튼을 눌러 복사된 내용을 그대로 붙여넣으세요!
우리 프로젝트의 3D R3F 아키텍처, Zustand 스토어 구조, CircuitPython 핀맵, REST 규격이 집약된 마스터 컨텍스트가 주입되어, 이후 어떤 수정을 요구해도 AI가 100% 정상 작동하는 코드를 생성합니다.

🌐 3D 가상 공간 (R3F)

Next.js 14 + React Three Fiber로 실시간 렌더링되며, 방의 가구와 센서 오브젝트가 물리 장치와 1:1로 결합되어 있습니다.

  • 스마트 거실 허브 (기본)
  • 스마트 팜 온실 (확장)
  • 스마트 팩토리 공정 (확장)

⚡ 하드웨어 코어 (Pico 2 W)

RP2350 듀얼코어 기반 Wi-Fi 마이크로컨트롤러로, CircuitPython 9.x 펌웨어가 REST API 서버를 구동합니다.

  • DHT11 온습도 센서 (GP15)
  • Cds 아날로그 조도 (GP26)
  • SG90 서보모터 (GP16)
  • RGB 3색 LED (GP18~20)

🤖 AI 바이브 코딩 (Context)

학생들이 복잡한 수동 코딩 없이, 생성형 AI에게 팀 주제와 핀맵만 말해주면 5대 핵심 코드가 자동 개조됩니다.

  • 시뮬레이션 모드 100% 지원
  • 원클릭 핀맵 교체기 탑재
  • 환각 없는 안전 변경 보증
STEP 02 · HARDWARE & REST API

2. 4종 레퍼런스 하드웨어 핀맵 & CircuitPython 통신 규격

실제 Raspberry Pi Pico 2 W와 브레드보드에 연결되는 표준 핀맵과 JSON REST API 규격을 안내합니다.

장치명 Pico 2 W 핀 신호 및 프로토콜 3D 가상 공간 연동 기능 REST API 엔드포인트
DHT11 온습도 GP15 (디지털) 단선 디지털 버스 (2초 주기 샘플링) 실시간 온도/습도 수치 플로팅 뱃지 표시 GET /api/status (temperature, humidity)
Cds 조도 센서 GP26 (ADC0) 16비트 아날로그 전압 (0~65535) 3D 가상 공간 앰비언트 자연광 밝기 실시간 제어 GET /api/status (light_adc)
SG90 서보모터 GP16 (PWM) 50Hz PWM (0~180도 각도 제어) 3D 스마트 도어 회전 및 온실 환기 돔 개폐 연동 POST /api/actuators/servo
RGB 3색 LED GP18, GP19, GP20 3채널 PWM (공통 캐소드 GND) 3D 펜던트 조명 발광 색상 및 ON/OFF 연동 POST /api/actuators/rgb

📡 CircuitPython CORS 지원 REST 서버

브라우저(Next.js)와 Pico 2 W 간 직접 통신 시 CORS 차단을 방지하기 위해 OPTIONS 프리플라이트 헤더를 지원합니다:

Access-Control-Allow-Origin: *
Access-Control-Allow-Methods: GET, POST, OPTIONS
Access-Control-Allow-Headers: Content-Type

🔌 하드웨어 없을 때: Mock 시뮬레이션 모드

하드웨어가 준비되지 않았거나 집에서 개발할 때는 대시보드 상단의 [시뮬레이션 모드]를 켜면 브라우저 내에서 가상 데이터가 생성되어 100% 동일하게 테스트할 수 있습니다.

STEP 03 · VIBE CODING CORE PRINCIPLES

3. AI 바이브 코딩 성공 공식 & 5대 핵심 수정 경계

왜 생성형 AI에게 질문하면 기존 코드를 다 망가뜨릴까요? 컨텍스트(Context) 엔지니어링의 핵심 원리를 이해합니다.

❌ 실패하는 학생의 질문 방식

"스마트팜 만들고 싶은데 코드 짜줘."

  • AI가 우리 프로젝트에 useIoTStore가 있는지 모름
  • CircuitPython 라이브러리 대신 아두이노 C++ 코드 생성
  • 기존 3D R3F 씬을 다 지우고 빈 컴포넌트 출력

✅ 성공하는 바이브 코딩 공식

"아래 5대 파일의 역할 분담에 맞춰 신규 센서/액추에이터를 연동해줘."

  • 기존 구조를 100% 보존하며 신규 장치만 정확히 결합
  • 단 한 번의 요청으로 3D 오브젝트와 UI 위젯 동시 완성
  • 환각(Hallucination) 제로 및 빌드 에러 0건 보증

🛡️ 반드시 준수해야 하는 5대 핵심 파일 수정 경계 (Change Boundary)

1. 핀맵 정의: context/CONTEXT_CIRCUITPYTHON_MAP.md

새 센서의 GPIO 핀 번호와 REST API 엔드포인트를 기재하여 Pico 2 W 펌웨어 code.py와 일치시킵니다.

2. 타입 정의: src/core/types/iot.ts

TypeScript 센서/액추에이터 인터페이스에 신규 필드(예: soil_moisture)를 정의합니다.

3. 가상 데이터: src/core/adapter/MockIoTAdapter.ts

하드웨어가 없을 때도 브라우저에서 동작할 수 있도록 시뮬레이션 데이터 생성 루프를 추가합니다.

4. 3D 공간 오브젝트: src/components/3d/

3D 씬 안에 화분, 기계 팔, 센서 노드 등 새 주제에 어울리는 Three.js 메쉬를 렌더링합니다.

5. 대시보드 UI 연동: src/components/ui/InspectorPanel.tsx & SensorOutputPanel.tsx

오른쪽 제어 패널에 새 센서 수치 게이지 카드와 액추에이터 원격 제어 토글/슬라이더 위젯을 배치합니다.

STEP 05 · TOPIC SHOWCASE A

5. 팀별 주제 Context 예시문 1~3 (스마트팜 / 팩토리 / 도어)

가장 인기 있는 3대 팀 프로젝트 주제의 완성된 Context 프롬프트 예시입니다. 복사해서 바로 활용하세요.

예시 1. 🌿 [스마트팜] 토양 수분 감지 및 자동 환기 온실 GP27(토양수분) + GP16(환기 서보) 
우리 팀은 스마트 에그리테크 프로젝트로 [스마트 팜 온실(Smart Farm Greenhouse)]을 제작합니다.
- 하드웨어: 토양 수분 센서를 Pico 2 W의 GP27(ADC1)에 연결하여 화분의 수분량(0~100%)을 실시간 측정합니다. 기존 DHT11(GP15) 온습도 센서도 함께 사용하여 온실 내부 온도를 모니터링합니다. SG90 서보모터(GP16)는 방문 대신 '온실 상단 환기 돔 개폐기'로 동작하며, RGB LED(GP18~20)는 일조량 부족 시 '식물 생장용 보라색 조명'으로 자동 점등됩니다.
- 3D 가상 공간: 거실 대신 투명 유리 프레임 온실 돔과 중앙 화분 배드를 배치하고, 서보 각도에 따라 지붕 돔이 부드럽게 열리는 3D 애니메이션을 연동해주세요.
- 대시보드 UI: 토양 수분 게이지 카드와 온실 환기 돔 수동 개폐 슬라이더를 추가해주세요.
예시 2. 🏭 [스마트 팩토리] 컨베이어 제품 감지 및 불량품 선별 GP17(초음파) + GP22(분류 서보) 
우리 팀은 스마트 제조 분야의 [스마트 팩토리 자동 분류 생산 라인]을 제작합니다.
- 하드웨어: 초음파 거리 센서를 Pico 2 W의 GP17(Echo), GP27(Trig)에 연결하여 컨베이어 벨트를 지나가는 부품의 높이 및 거리를 계측합니다. 정상 규격을 벗어난 물품이 감지되면(거리 < 8cm) 서보모터(GP16)가 '불량품 푸셔 암'을 90도 회전시켜 배출 라인으로 밀어냅니다. RGB LED(GP18~20)는 정상 가동 시 녹색, 불량 감지 시 적색 경고등으로 점멸합니다.
- 3D 가상 공간: 산업용 컨베이어 벨트, 로봇 암 지지대, 물품 박스 메쉬를 3D 공간에 배치하고 서보모터 회전에 맞춰 푸셔 암이 움직이도록 연동해주세요.
- 대시보드 UI: 생산 라인 분당 통과 수량 카운터와 불량률(%) 통계 위젯을 추가해주세요.
예시 3. 🚪 [스마트 보안] 비접촉 출입 인증 및 자동 개폐 도어 GP28(PIR 인체감지) + GP16(도어 서보) 
우리 팀은 주거 안전을 위한 [비접촉 모션 감지 스마트 보안 도어락]을 제작합니다.
- 하드웨어: PIR 인체 모션 감지 센서를 Pico 2 W의 GP28(Digital In)에 연결하여 도어 앞 사람의 접근을 감지합니다. 등록된 인증 요청이 들어오면 SG90 서보모터(GP16)가 90도로 회전하여 도어를 개방하고 5초 후 자동으로 잠깁니다. RGB LED(GP18~20)는 대기 중 파란색, 인증 성공 시 초록색, 무단 침입 감지 시 빨간색 사이렌 점멸을 수행합니다.
- 3D 가상 공간: 보안 도어 프레임과 도어락 키패드를 강조하고, 도어 개폐 각도를 Three.js 피벗 회전으로 부드럽게 연동해주세요.
- 대시보드 UI: 실시간 출입 로그 기록 리스트와 긴급 도어 강제 잠금 스위치를 추가해주세요.
STEP 06 · TOPIC SHOWCASE B

6. 팀별 주제 Context 예시문 4~6 (에너지 / 화재방재 / 헬스케어)

환경, 안전, 헬스케어 등 사회적 문제를 해결하는 다양한 아이디어의 Context 프롬프트 예시입니다.

예시 4. ⚡ [스마트 에너지] 대기전력 차단 및 조도 연동 절전 플러그 GP26(Cds 조도) + GP14(릴레이) 
우리 팀은 탄소 중립을 위한 [친환경 스마트홈 대기전력 차단 시스템]을 개발합니다.
- 하드웨어: Cds 조도 센서(GP26)로 실내 조도를 측정하고, 재실자 부재 시 대기전력 차단 릴레이(GP14)를 OFF합니다. SG90 서보모터(GP16)는 '스마트 블라인드 각도 조절기'로 작동하여 외부 태양광 유입량을 조절하고, RGB LED(GP18~20)는 현재 소비 전력 단계(초록: 절전, 노랑: 표준, 빨강: 과부하)를 표시합니다.
- 3D 가상 공간: 거실 창문에 3D 블라인드 루버를 배치하여 서보 각도에 따라 블라인드가 열리고 닫히는 채광 시뮬레이션을 구현해주세요.
- 대시보드 UI: 금일 누적 절감 전력량(kWh) 게이지와 탄소 배출 저감 지표를 시각화해주세요.

8. UI 3D 레이어링 3대 원칙 & 트러블슈팅 FAQ

모달창이 3D 요소에 가려지거나 카메라 시점이 흐트러졌을 때의 완벽 해결 공식과 자주 묻는 질문입니다.

💡 반드시 준수해야 하는 3D UI 레이어링 3대 공식

  1. Drei <Html> zIndexRange 제한: 모든 3D 어노테이션 태그에 zIndexRange={[10, 0]}을 지정합니다. Drei 기본값인 1,600만 대신 최대 10으로 제한하여 모달창(z-[100])을 뚫고 올라오는 현상을 차단합니다.
  2. 모달 오픈 시 3D 태그 자동 언마운트: page.tsx의 isModalOpen 상태를 전달받아, 모달이 열려 있을 때는 {!isModalOpen && <Html>...</Html>}로 3D 뱃지를 즉시 숨깁니다.
  3. 카메라 뷰 복귀 & 조감도(Top-down) 토글: 좌측 툴바의 '3D 가상 공간 뷰' 버튼을 누르면 기본 입체 각도로 복귀하며, 좌하단 '전체 조감도' 버튼으로 상공 11m 탑다운 시점을 자유롭게 전환합니다.

Q1. Pico 2 W의 IP 주소를 어떻게 확인하나요?

Pico 2 W를 PC에 USB로 연결한 후 Thonny IDE 시리얼 콘솔을 열고 보드를 리셋(Ctrl+D)하면 터미널에 Wi-Fi Connected! IP: 192.168.x.x가 출력됩니다. 대시보드 좌측 Wi-Fi 모달에 해당 IP를 입력하세요.

Q2. 공간 목록에서 공간 이름을 어떻게 바꾸나요?

좌측 '스마트 공간 목록'의 각 공간 우측 [점 3개 아이콘]을 누르고 [✏️ 이름 바꾸기]를 선택하면 전용 팝업이 열려 원하는 팀 명칭으로 즉시 수정할 수 있습니다.

Q3. CircuitPython에서 CORS 오류가 발생합니다.

브라우저 개발자 도구 콘솔에 CORS 에러가 보이면 firmware/pico2w/code.py의 각 라우트에 [GET, POST, OPTIONS] 메서드가 등록되어 있는지, 그리고 헤더에 Access-Control-Allow-Origin: *가 포함되어 있는지 확인하세요.

Q4. 시뮬레이션 모드와 하드웨어 모드는 어떻게 전환하나요?

대시보드 상단 헤더 중앙의 [시뮬레이션 / 하드웨어] 토글 알약 버튼을 누르거나, 좌측 Wi-Fi 모달 창에서 원클릭으로 손쉽게 전환할 수 있습니다.
